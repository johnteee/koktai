# 聲韻資料表（`a-tsioh_sandbox/data/`）

兩張手工編定的 JSON 表，驅動統一索引的平水層。編定原則：**能溯源者溯源，
推斷者標注**；表內 `_meta` 皆自述出處。

## 1. `pingshui_tl.json` — 平水韻系 → 台羅文讀韻母

**出處**：`ExternalRef/平水韻注音符號編碼.pdf`（王庚春，2016-03-24）。
該文以吳守禮注音為藍本，逐韻系列出「平水四聲韻目＋方音符號＋台羅拼音」。
文中另創的衍生方音符號不在 Unicode，**只收台羅層**；各系四聲相配依原文各節末表。

結構：

```jsonc
"series": {
  "東": { "pingshui": {"平":"東","上":"董","去":"送","入":"屋"},
          "tl": ["ong","iong"], "tl_ru": ["ok","iok"],
          "colloquial": ["ang","iang"] },   // 原文註記之白話對應（僅部分系有）
  …30 韻系
}
```

收錄要點（摘自 PDF 各節）：

|---|---|---|---|
| 東/冬/江/陽 | ong, iong | ok, iok | 白話 ang/iang；江系鼻音濃（原文以衍生符區分，台羅同形） |
| 支/微 | i, ui | — | 微系喙型齊扁（衍生符層次，台羅同形） |
| 魚 | u, ir | — | 開口；泉腔 ir |

| 文 | un, in | ut, it | 欣韻開口 in |
| 元 | uan, ian, un | uat, iat, ut | 魂痕 un |
| 寒/刪 | an, uan | at, uat | 黠帶鼻（ㆩ 層次） |
| 先 | ian, uan | iat, uat | |
| 蕭/肴 | iau / au, iau | — | |

用途：join 得到平水部後 → 查本表得「預期台羅文讀韻母」，
與 koktai 實測讀音互為一致性檢核（不合者即真異讀或標音問題）。

## 2. `kuangx_pingshui.json` — 切韻系 206 韻目 ↔ 平水 106 部

**出處**：平水韻標準併合（佩文詩韻系統）＋ ytenx `kyonh/YonhMiuk.txt` 字形。
［此表為標準韻書學知識的編碼，非本專案原創研究；已按 ytenx 拼寫核字。］

結構：

```jsonc
"variants": { "真":"眞", "皓":"晧", "號":"号", "寢":"寑", "艷":"豔",
              "驗":"釅", "痲":"麻", "麽":"麻", "襇":"襉" },   // 引文異體 → ytenx 正字
"pingshui": {
  "黠": { "tone":"入", "series":"刪", "kuangx": ["黠","鎋"] },
  …106 部（平30 上29 去30 入17）
}
```

- `kuangx` 列出併入該平水部的廣韻韻目（ytenx 拼寫：眞諄臻、晧、号、寑、豔㮇釅…）。
- 每部帶 `series`（30 韻系）→ 串接 `pingshui_tl.json`。
- 反查（廣韻目→平水部）由程式建立；平水部名本身也可查（處理引文直用平水目的情況）。

用途：
1. 「廣韻反切·平水寬」join（引文韻目與小韻韻目同平水部即接受）。
2. 任何 join 結果 → 平水部 → 預期台羅文讀。

## 維護注意

- `variants` 只收**語料實見**的寫法；新增卷次若出現新異體，先在
  `ytenx-correspondence.md` 的方法下重跑韻目清點再擴充。
- 兩表皆為「先驗知識層」：**不要**用索引輸出反向改表（避免循環論證）；
  例外請在 `_meta.note` 記錄依據。
