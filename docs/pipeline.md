# 轉換管線 v2（koktai-dic/2）

## 管線

```
betaNNk.dic (Big5+EUDC)
  │ perl a-tsioh_sandbox/recode_utf8.pl        # CP950→UTF-8；造字→U+F0000+big5
  ▼
UTF-8 .dic 文本
  │ python3 a-tsioh_sandbox/dic2json.py        # 全結構解析＋造字解碼（koktai_dic.py）
  ▼
koktai-dic/2 JSON（結構＋<rt>/<glyph:>標記）
  │ python3 a-tsioh_sandbox/rt2pronun.py       # 方音→台羅/白話字＋逐字對齊 tokens
  ▼
json/NN.json
```

批次：`perl gen_json.pl`（26 卷約 40 秒）。

### v1 → v2 的管線變更

| | v1 | v2 |
|---|---|---|
| 階段 | `recode → dic2json → jade-unescape.pl → rt2pronun` | `recode → dic2json → rt2pronun` |
| 造字解碼 | Perl `jade-unescape.pl`（需 CPAN `JSON`、`File::Slurp`） | 併入 `dic2json.py`（`koktai_dic.to_rt_markup`，零額外依賴） |
| 輸出 | 詞條扁平 list（`[{entry, heteronyms:[…]}]`） | `koktai-dic/2` 樹（章→單字→詞條） |

`jade-unescape.pl` 保留於 repo 供 jade（HTML 預覽）舊路徑使用，JSON 管線不再經過。

## v1 資訊遺失清單（v2 全數收回）

1. **`.本文` 單字條目整塊丟棄**——v1 `dic2json.py` 以 `.本文` 作「清 buffer」訊號。
   遺失：字頭、字頭注音、**11,002 筆反切引註**、國音/台甘/普閩讀音列。
2. **`.章首` 章節音節丟棄**（1,446 筆國音注音＋羅馬字錨點）。
3. **漢字↔注音對齊丟失**——v1 把 `<rt>` 全部抽出串接成 `pronun_bopo` 後刪除，
   無法回答「哪個字讀哪個音」。v2 產出 `tokens[]` 逐字對齊＋保留 `sentence_ruby` 原文。
4. **卷 02–26 輸出全空**（0 byte JSON）。v2 全卷產出。
5. **解析失敗行印到 stdout**（`print("unanalyzed", …)`）汙染 JSON；v2 進
   `unparsed`/`stray` 結構欄位＋stderr 統計。
6. **格式碼裸刪**不留痕；v2 各層保留 `raw`（造字以 `&#xfXXXX;` ASCII 逃逸，可逆，
   且不會被後續文字階段誤改）。

## 解析器演進備忘（為何長這樣）

- `.本文` 成對出現 → 空塊；只含空白的塊不得成為條目（曾造成 1,200 幽靈單字，實際 600）。
- 舊排版（卷 3:2,816→911、卷 12:3,306→1,201 修正前後）：
  - 字頭段碼無 `bb1`、引註尾是 `~t84;` → 段落掃描改為「任意 `~code;` 段、
    `t84` 起算尾」。
  - 讀音列多標籤一行 → `READING_LABEL_RE` 以 search 掃描全行、按標籤位置切段。
  - `.本文` 兼段落分隔 → 「無頭＋無讀音＋有詞條」塊併回前一單字條目。
- 反切在字頭尾以 `。；` 分段逐段解析；`廣韻：` 前綴作為該段預設來源；
  無法解析片段進 `annotation_notes`，不丟。
