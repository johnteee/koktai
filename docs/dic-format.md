# `.dic` 原始檔案格式規格

來源：吳守禮《國臺對照活用辭典》排版檔 `beta01k.dic` … `beta26k.dic`。
編碼：Big5（CP950）＋使用者造字（EUDC，U+E000–F8FF 區）。行尾 CRLF。

## 0. 前處理：`recode_utf8.pl`

- CP950 → UTF-8。
- 造字重映射：BMP PUA 字元 → **U+F0000 ＋ 原 Big5 碼位**（例：Big5 `0xFAB6` → U+FFAB6）。
  之後所有工具以 `U+F0000–U+FFFFF` 識別造字，`hex = codepoint − 0xF0000`。
- 格式碼 `~XX;` 統一轉小寫。

## 1. 檔案巨觀結構

```
.章首
ㄅㄚ ~t112fd0;[ba]          ← 章節音節：國音注音＋羅馬字

.本文                        ← （常成對出現：前一個關閉、後一個開啟）
.本文
<單字頭行>
<讀音列…>
<詞條…>
.章首
…
```

- `.章首` 後第一個非空行為章節音節行；輕聲章節作 `~bt180;·~bt0;ㄅㄚ …[·ba]`。
- `.本文` 是單字條目分隔符。**卷 3、12 等舊排版把 `.本文` 當一般段落分隔狂灑**
  （卷 3 有 3,780 個 `.本文` 但僅 911 個實際單字），解析器須把「無字頭、無讀音列、
  只有詞條」的區塊併回前一個單字條目。

## 2. 單字頭行（兩式）

```
新式（卷1 等，524 筆明體＋76 筆楷體/卷）：
~fm7t168bb1;八~fm3t168bb1;󿪶~fm3t84bb1;　布拔切，黠韻
 └字頭(明體)   └注音字形(造字)  └t84 起為引註尾

楷體字頭（台語造字，可帶「/標準字」替代）：
~fkt168bb1;󿫠~fm3t168bb1;󿪶~fm7t168bb1;/巴~fm3t168bb1;󿪶~fm3t84bb1;　邦加切，麻韻

舊式（卷3、12）：
~fm7t168;抹~fm3;󿻾~t84;　莫葛切，末韻
```

判定規則：行首符合 `^~f[a-z0-9]*t168`；段落以 `~code;` 切分，`code` 含 `t84`
起即為引註尾；`fk*` 段為楷體（造字先查 `mapping.json` 罕用漢字）、其餘明體。
字頭段與注音字形段交錯；注音字形 = 查 `m3.json`/`k.json` 有方音值的造字。

### 引註尾（反切）

- 530/600（卷1）字頭帶引註；全語料 11,002 筆。
- 形態：`X切，Y韻`、`廣韻：A切，B韻。C切，D韻`、`E切，F韻(正韻)`、
  `←G切，H韻(廣韻)`（← = 由他音導出）、`房六切，入屋韻`（調前綴）、
  非反切註記（`康典未收字。`）。
- 來源標記統計（卷1）：未標 590、康典 19、唐韻 12、廣韻 7、集韻 7、正韻 3。
  未標者實為混合來源（大量集韻式反切；見 ytenx-correspondence.md）。

## 3. 讀音列

```
新式（一標籤一行）：
~fm7;國音~fm3t42;　~t84;󿪶，下一字為去聲時…~bt315;∥~bt0;
~fm7;台甘~fm3t42;　~t84;(文)󿭉(語)󿫥(漳)󿯰(廈、泉)~bt315;∥~bt0;
~fm7;普閩~fm3t42;　~t84;(文)󿭉(白)󿯰。

舊式（多標籤一行，∥ 分隔）：
~fm7;國音…~bt315;∥~fm7bt0;台甘…~bt315;∥
```

- 標籤固定三種：`國音`（華語）、`台甘`（台語·甘為霖系）、`普閩`（普閩典）。
- 內容為「(語域)造字…」序列；語域標記見 `(文)(語)(白)(漳)(泉)(廈)(俗)(罕用)…`。
- 造字＝方音符號讀音字形（一字形＝一完整音節，含調號）。

## 4. 詞條行

```
~t96;【~fb7bb1;八~fm3bb1;󿪶~fb7bb1;方~fm3bb1;󸥏~fm3bb1;】~t84;~fd6;1~fd0; [名] 釋文…(台)台文…
```

- `~t96;【詞頭】~t84;` 開頭；詞頭內 `~fb7*` 段為漢字、`~fm3*` 段為注音字形。
- `~fd6;N~fd0;` = 同形詞條編號（heteronym n）。
- `[POS]` 詞性標記。
- 釋文以 `(台)`/`(國語)` 切換語言；台文句 = 逐漢字後跟注音字形。
- 續行（如 `~fk;類語~fm3;：…`）屬前一詞條。
- 章首之後、第一個 `.本文` 之前可出現「孤兒詞條」（如擬音詞），歸屬章而非單字。

## 5. 行內格式碼

| 碼 | 意義 |
|---|---|
| `~fm3;` / `~fm7;` | 明體（正文／粗明） |
| `~fk…;` | 楷體起（台語字層；至下一個 `~fm3;`/`~fm7;` 止）→ 解析為 `<k>…</k>` |
| `~fb7…;` | 粗體（詞頭漢字） |
| `~tNNN…;` | 定位/欄位（`t168`=字頭欄、`t84`=內文欄、`t96`=詞條列、`t112fd0`=章首） |
| `~btNNN;…~bt0;` | 上下標區（`·` 輕聲點、`∥` 欄位分隔） |
| `~fd6;…~fd0;` | 小字（詞條編號） |

## 6. 造字（PUA）語意分區

重映射後 `U+F0000–U+FFFFF`，`hex = cp − 0xF0000`：

| 區段 | 語意 | 解碼 |
|---|---|---|
| `fc6a1–fc6a9` | 圈號 ①–⑨ | `chr(0x245F + (cp−0xFC6A0))` |
| `fc000–fcfff`（其餘） | **內文字元區**：正文用字（癶、ㄆㄚ、罕用字）| `m3.json[hex]` **裸放**（不是 ruby！）|
| 其他區段（明體） | 注音字形（ruby） | `m3.json[hex]` → `<rt>方音</rt>`；無表 → `mapping.json`（罕用漢字）→ `<glyph:m3/hex>` |
| 楷體區（`<k>…</k>` 內） | 台語字／楷注音 | `mapping.json`（罕用漢字優先）→ `k.json[hex]` → `<rt>…</rt>` → `<glyph:k/hex>` |

> 歷史教訓：把 `fc000–fcfff` 一律當 ruby 會令「卡癶襠」變「卡襠」＋幽靈注音 `癶`。
> 此區承接舊 `jade-unescape.pl` 第 15–18 行的「裸放」語意。
