# 方音符號 ↔ 台羅 ↔ 白話字 轉換方法論

實作：`a-tsioh_sandbox/rt2pronun.py`。基底為吳守禮台灣方音符號系統。

## 對照表

三張正向表（台羅→方音）定義於檔頭，反查表由程式反轉生成：

- **聲母**：`p ㄅ、ph ㄆ、m ㄇ、b ㆠ、t ㄉ、th ㄊ、n ㄋ、l ㄌ、k ㄍ、kh ㄎ、g ㆣ、ng ㄫ、h ㄏ、ts ㄗ、tsh ㄘ、s ㄙ、j ㆡ`；顎化列 `tsi ㄐ、tshi ㄑ、si ㄒ、ji ㆢ`（反查時剝 `i`，與韻母 ㄧ 併拼）。`f ㄈ` 僅華音。
- **韻母**：約 90 鍵，含鼻化（`ann ㆩ、onn ㆧ…`）、入聲尾（`-h ㆷ、-p ㆴ、-t ㆵ、-k ㆶ`）、泉腔（`ir ㆨ、er ㄮ`）、`ee ㄝ、or ㄛ、oi ㆦㄧ` 等方言音。
- **聲調**（15 聲鍵盤制，見 `font/tai.c`、README）：

| 調 | 符號 | 備註 |
|---|---|---|
| 1 | （無） | 陰平 |
| 2 | ˋ | 陰上 |
| 3 | ˪ | 陰去 |
| 4 | （無，入聲尾） | 陰入 |
| 5 | ˊ | 陽平 |
| 6 | ˫ | 陽上（與 7 同符，反查慣例取 7） |
| 7 | ˫ | 陽去 |
| 8 | ㆐ 或 **◌ ͘**（U+0358 右上點，常前置空白） | 陽入 |
| 9 | ^ | 高升（雙疊詞） |
| 0 | ˙（可前置） | 輕聲 |

## 音節切分演算法（`analyze_bopo`）

```
去 〾（異體記號）→ 若含國語專用符號 → 整串標 cmn，不轉
迴圈：跳空白 → 前置 ˙ 記輕聲 → 取聲母（單字元查表）
     → 韻母「最長匹配」（反查鍵按長度降冪，ㄨㆩㆷ 先於 ㄨ）
     → 聲調：容許「(空白)◌ ͘」＝8；查調符；無則入聲尾→4、否則→1
     → 輕聲待決 → 調=0
輸出 {lang: nan|partial|unknown, tl, poj, errors[]}；失敗位置記 errors，不再印 stderr
```

**國語分類**：音節含 `ㄓㄔㄕㄖㄦㄩㄟㄡㄈ` 任一或調號 `ˇ` → `lang:"cmn"`，保留注音、
不產生台羅（v1 會硬轉出垃圾或報 13,124 行警告）。ˋ/ˊ 台華同形，無法字元級判別，
依上下文欄位（國音列、國語句）自然歸位。

## 台羅 → 白話字（`臺羅轉白話字`）

- 聲母：`ts→ch、tsh→chh`，餘同。
- 韻母：`oo→o͘、ua→oa、ue→oe、ing→eng、ik→ek、nn→ⁿ（nnh→ⁿh）`。
- 調符標位：`o͘` 優先；三元音 `iau/oai` 標 a；雙元音依 i 位置與鼻化尾規則；
  單元音直標；`ng`→n、`m`→m。調 1/4 無符；調 9 用雙抑揚（ă）。

## 逐字對齊（`tokenize_ruby`）

掃描字串的 token 化規則：

- `<rt>R</rt>` 附著於**其前最近的基底**（漢字／`<mark>` 造字／`<glyph:>`）。
- `/<rt>…` 或 `(/替字)<rt>…` → 前一 token 的**又讀**（`ruby[]` 多值）。
- `·` → 該 token `neutral: true`（輕聲）。
- 連續 `<rt>` 無新基底 → 併入同 token。
- 無基底可附 → `han:null` token（**不丟**）。

驗證抽樣：`方→hong1(文)/hng1(白)/pang1(白)`、`八→pat4文/peh4語/pueh4漳`、
`食→tsiah8白/sit8文`、`ㄍㄨ→ku1`（kuh1 幽靈消滅）、`ㄒㄧㆵ ͘→sit8`、`ㄑㄩˊ→cmn`。
