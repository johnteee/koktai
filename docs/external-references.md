# `ExternalRef/` 外部文件盤點

王庚春（NatureRoger）「台語漢文輔助系統」相關文件六件。逐件記錄可用性與本專案取用方式。

## 1. 平水韻注音符號編碼.pdf ★ 已取用

- 王庚春，2016-03-24。〈漢文台語唐宋（平水）韻注音編碼〉。
- 內容：以吳守禮 46 符注音為藍本，為平水韻各韻系設計注音標法；
  逐系（東冬江陽支微魚虞齊佳灰真文元寒刪先蕭肴豪歌麻庚青蒸尤侵覃鹽咸）列
  四聲韻目、發音要領（喙型/鼻腔/頓音）、例字＋台羅拼音；四聲八調對照表；
  聲母轉碼規則（ts=ㄗ/tsi=ㄐㄧ、tsh=ㄘ/tshi=ㄑㄧ、s=ㄙ/si=ㄒㄧ、j=ㆡ/ji=ㆢㄧ）。
- **取用**：編定為 `a-tsioh_sandbox/data/pingshui_tl.json`（見 data-tables.md）。
- 界限：文中大量**自創衍生方音符號**（如帶鉤 ㄏ、鼻化 ㆭ 變體）無 Unicode 碼位，
  PDF 抽字時成空白——只能收台羅層；衍生符層次若要保留需向作者取原始造字檔。

## 2. HanBunDatabase.accdb ✗ 加密不可讀

- MS Access ACE14（`mdb-ver` 識別為 ACE14；`file` 識別 Access DB）。
- **加密證據**：0x1000、0x2000 起頁面為純亂數熵值；`mdb-tables` 讀頁失敗
  （page 2 首位元組 0x3C 非表定義頁）。研判為資料庫密碼加密（RC4/Agile）
  ［推斷：僅由頁面熵值與工具行為判定，未逆向確認演算法］。
- 依簡介 PDF，內容應為：《廣韻》切語上下字↔台羅對照（近 2,000 字）、
  康熙字典所引其他韻書（唐韻/集韻/韻會/正韻/韻補）反切上下字 1,200+ 字、
  漢字釋義 9,000+ 條。
- **替代**：本專案以開放資料重建同款對照——ytenx 廣韻/正韻小韻表 × koktai
  反切引註 × 台羅讀音（見 unified-index.md）。若日後取得密碼，
  可將其切語對照表作為 join 的第三驗證源。

## 3. 台灣語 漢文輔助系統 簡介 文件.pdf ★ 已取用（背景）

- 系統功能：查漢字（文讀/白話/上古音之台羅＋吳守禮注音＋字義）、切音輔助
  （反切上下字→音韻拼音）、文章轉拼音、編稿注音。
- 支援 Windows XP–10；Web 版 `dic.taigubun.org`。
- 價值：說明 accdb 的內容與建置方法論（康熙字典切出台羅再人工校訂）——
  與本專案 join 方法論同構，可互為印證。
